#  LittleNotes — A Cozy Notebook for Students

> **"Your notes should adapt to the way you think, not force you to organize your thoughts before you can write them down."**

LittleNotes is an effortless, warm study space built for students to quickly capture lecture thoughts, understand difficult concepts, and save code snippets without dealing with bloated productivity systems.

---

## Core Pillars & Features

### 1. The Thought Flow (Signature Experience)
- **Step 1: Catch it (`Inbox`)**
  - Open the app, type in the frictionless capture bar (`Enter` to save instantly).
  - No need to decide folders or tags beforehand. Captured automatically to device storage.
- **Step 2: Shape it**
  - Enrich notes when you're ready: assign to a Notebook (e.g. *AI & ML*, *My Labs*, *Code Corner*, *Japanese Study*), choose cozy pastel colors, add checklists with interactive tickboxes, or attach monospaced code blocks.
- **Step 3: Reuse it (`Exam Mode`)**
  - Turn notes into revision questions and flashcards.
  - Active recall mode flips cards to test your understanding before midterms and finals.

### 2. Cozy Aesthetics & Tablet Inspiration
- **Grid Paper, Ruled Paper & Plain Paper**: Seamlessly switch background textures inspired by Japanese stationery and tablet study apps.
- **Kawaii & Functional Sticky Note Templates**:
  - Illustrated corner companions: *Bamboo Panda*, *Teacup Kitten*, *Pond Duckling*, *Strawberry Bloom*, *Study Bot*, *Carrot Patch*.
  - Functional Todo Stickies & Code Cards.
- **Café Color Palette**:
  - `Paper` (`#FAF6EF`), `Lilac` (`#E7DDF8`), `Sage` (`#DCE9DD`), `Blush` (`#F3DCD6`), `Butter` (`#FEF08A`), `Sky` (`#E0F2FE`), `Peach` (`#FFEDD5`), `Ink` (`#37343C`).
- **Typography**:
  - Headings: *Lora* (warm, characterful serif)
  - Body: *Inter* (clean, fatigue-free reading)
  - Code: *JetBrains Mono* (monospaced syntax preservation)

### 3. Practical Student Tools
- **Code Notes**: Indentation-preserving monospaced blocks with language selector and 1-click clipboard copy.
- **Interactive Checklists**: Tick off tasks directly from the sticky note card.
- **Fast Instant Search**: Real-time filtering across note titles, contents, code snippets, tags, and revision prompts.
- **Reliable Offline Saving**: All notes and notebooks persist locally in your browser (`localStorage`) with 1-click JSON backup export & restore.
